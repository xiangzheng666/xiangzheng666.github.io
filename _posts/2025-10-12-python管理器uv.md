## 一、uv 简介

**特点：**
- 🚀 极快：基于 Rust 实现，比 pip/Poetry 快数十倍。
- 🧩 一体化：支持虚拟环境、依赖安装、项目构建、发布。
- 🛠️ 兼容性好：兼容 `pyproject.toml`、`requirements.txt`、`Pipfile` 等格式。
- 🔒 可复现：支持锁定依赖（`uv.lock`），确保环境一致。

## 二、安装 uv

### 方式 1：官方推荐安装
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 方式 2：使用 pipx 安装
```bash
pipx install uv
```

### 验证安装
```bash
uv --version
```

## 三、常用命令概览

| 命令 | 说明 |
|------|------|
| `uv init` | 初始化 Python 项目 |
| `uv add <pkg>` | 安装依赖并自动更新锁文件 |
| `uv remove <pkg>` | 删除依赖 |
| `uv sync` | 根据锁文件安装所有依赖 |
| `uv run <cmd>` | 在虚拟环境中运行命令 |
| `uv lock` | 生成依赖锁文件 |
| `uv build` | 构建 wheel 或源码包 |
| `uv publish` | 发布到 PyPI |
| `uv venv` | 管理虚拟环境 |

## 四、快速上手示例

### 1. 初始化项目

```bash
mkdir myapp
cd myapp
uv init
```

生成的文件结构：
```
myapp/
├── pyproject.toml
├── README.md
└── myapp/__init__.py
```

### 2. 安装依赖

```bash
uv add requests flask
```

自动创建虚拟环境（`.venv/`）并生成：
- `pyproject.toml`（依赖定义）  
- `uv.lock`（锁定依赖版本）  

### 3. 运行脚本

```bash
uv run python main.py
```

相当于自动激活虚拟环境再执行脚本。

## 五、虚拟环境管理

### 1. 创建虚拟环境

```bash
uv venv .venv
```

### 2. 激活虚拟环境

```bash
source .venv/bin/activate  # Linux / macOS
.venv\Scripts\activate   # Windows
```

### 3. 删除虚拟环境

```bash
uv venv remove
```

## 六、依赖管理详解

### 1. 添加依赖

```bash
uv add numpy==1.26.0
uv add pandas --dev
```

选项：
- `--dev`：添加为开发依赖。
- `--optional`：可选依赖（如插件或扩展）。

### 2. 移除依赖

```bash
uv remove flask
```

### 3. 查看依赖树

```bash
uv tree
```

### 4. 同步依赖（基于锁文件）

```bash
uv sync
```

## 七、构建与发布

### 1. 构建包

```bash
uv build
```

生成：
```
dist/
├── myapp-0.1.0.tar.gz
└── myapp-0.1.0-py3-none-any.whl
```

### 2. 发布到 PyPI

```bash
uv publish --token <pypi-token>
```

支持 `.pypirc` 配置文件。

## 九、常见使用场景

### 1. 在现有项目中迁移到 uv

```bash
uv init --from pyproject.toml
uv lock
uv sync
```

### 2. 临时运行 Python 脚本

```bash
uv run python -c "import requests; print(requests.__version__)"
```

### 3. 管理多个 Python 版本

```bash
uv python install 3.11
uv python list
uv python use 3.11
```

### 4. 安装指定依赖版本组合

```bash
uv add "fastapi[all]" uvicorn[standard]
```

## 十、进阶技巧

### 1. 离线安装

## 十一、实战示例：FastAPI 项目

```bash
# 初始化项目
uv init fastapi-demo
cd fastapi-demo

# 添加依赖
uv add fastapi uvicorn

# 创建 main.py
echo '
from fastapi import FastAPI
app = FastAPI()

@app.get("/")
def hello():
    return {"message": "Hello from uv!"}
' > main.py

# 运行项目
uv run uvicorn main:app --reload
```

访问 `http://127.0.0.1:8000` 即可看到运行结果。

## Python 版本管理

安装和管理 Python 版本。

- `uv python install`：安装 Python 版本。
- `uv python list`：查看可用的 Python 版本。
- `uv python find`：查找已安装的 Python 版本。
- `uv python pin`：为当前项目指定使用的 Python 版本。
- `uv python uninstall`：卸载 Python 版本。

------

## 脚本

运行独立的 Python 脚本（如 `example.py`）。

- `uv run`：运行脚本。
- `uv add --script`：为脚本添加依赖。
- `uv remove --script`：从脚本中移除依赖。

------

## 项目

创建并管理包含 `pyproject.toml` 的 Python 项目。

- `uv init`：创建一个新项目。
- `uv add`：向项目添加依赖。
- `uv remove`：从项目中移除依赖。
- `uv sync`：同步项目依赖到环境。
- `uv lock`：为项目依赖创建锁文件。
- `uv run`：在项目环境中运行命令。
- `uv tree`：查看项目的依赖树。
- `uv build`：构建项目的分发包。
- `uv publish`：将项目发布到包索引。

------

## 工具

- `uvx` / `uv tool run`：在临时环境中运行工具。
- `uv tool install`：全局安装工具。
- `uv tool uninstall`：卸载工具。
- `uv tool list`：列出已安装的工具。
- `uv tool update-shell`：更新 shell，使工具可执行文件生效。

------

## pip 接口

手动管理环境和包，适用于需要精细控制的传统工作流或场景。

- `uv venv`：创建一个新的虚拟环境。

### 管理环境中的包pip

- `uv pip install`：安装包到当前环境。
- `uv pip show`：显示已安装包的详细信息。
- `uv pip freeze`：列出已安装包及其版本。
- `uv pip check`：检查当前环境中的包是否兼容。
- `uv pip list`：列出已安装的包。
- `uv pip uninstall`：卸载包。
- `uv pip tree`：查看环境的依赖树。

- `uv pip compile`：将需求文件编译为锁文件。
- `uv pip sync`：根据锁文件同步环境。



------

## 实用工具

管理和查看 uv 的状态，如缓存、存储目录，或执行自更新：

- `uv cache clean`：清理缓存条目。
- `uv cache prune`：清理过期的缓存条目。
- `uv cache dir`：显示 uv 缓存目录路径。
- `uv tool dir`：显示 uv 工具目录路径。
- `uv python dir`：显示 uv 安装的 Python 版本路径。
- `uv self update`：将 uv 更新到最新版本。
