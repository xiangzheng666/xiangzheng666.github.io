一、Git 基本概念

Git 是一个 分布式版本控制系统，可以记录文件的历史修改，支持多人协作开发。

名称 含义 作用
工作区（Working Directory） 当前看到的项目目录 编写代码、修改文件的地方
暂存区（Staging Area / Index） 一个临时存放修改的区域 用来组织下一次要提交的内容
本地仓库（Local Repository） 存放所有提交历史的数据库 保存完整版本历史，可以离线操作
远程仓库（Remote Repository） 托管在服务器上的仓库 多人协作、备份与共享代码

数据流动过程如下：

1

工作区 → 暂存区 → 本地仓库 → 远程仓库

二、查看仓库状态

git status

显示当前工作区与暂存区的状态。

1

git status

常见状态：

  • Untracked files：新创建的文件，还未被 Git 跟踪。
  • Modified：文件被修改但未添加到暂存区。
  • Staged（绿色）：文件已添加到暂存区，等待提交。
  • Clean：没有任何改动。

三、文件管理命令

操作 命令 说明
添加文件到暂存区 git add <文件> 准备提交该文件
添加全部文件 git add . 将所有修改添加到暂存区
提交修改 git commit -m "描述信息" 将暂存区内容保存到本地仓库
从暂存区移除 git restore --staged <文件> 撤销已添加到暂存区的更改
丢弃修改 git restore <文件> 撤销工作区中的未暂存修改
删除文件 git rm <文件> 从版本库中删除文件

四、版本历史管理

操作 命令 说明
查看提交历史 git log 查看完整提交记录
简化查看 git log --oneline --graph --decorate --all 图形化查看提交树
回退版本 git reset --hard <commit_id> 回退到指定版本
修改上次提交 git commit --amend 修正描述或补交文件

五、分支（Branch）

什么是分支？

分支是版本线的“副本”，每个分支相互独立，修改互不影响。
它允许你在不破坏主线的前提下，进行新功能开发或试验。

操作 命令 说明
查看分支 git branch 查看所有本地分支
创建分支 git branch dev 新建名为 dev 的分支
切换分支 git switch dev 进入 dev 分支
创建并切换 git switch -c dev 一步完成创建与切换
合并分支 git merge dev 将 dev 分支的修改合并到当前分支
删除分支 git branch -d dev 删除本地分支

作用：

  • 分支的核心意义在于 并行开发。
  • 主分支（main/master）可保持稳定版本，而开发分支可自由实验。

六、标签（Tag）

什么是标签？

标签（Tag） 是某个提交（commit）的永久标记。
它通常用于标记项目的“版本发布点”，例如 v1.0、v2.0 等。

作用

  • 帮助记录 版本发布 的节点。
  • 在后续回溯或修复 Bug 时，可以清楚知道对应版本的代码。
  • 可直接从标签检出（checkout）到该版本，确保代码环境一致。

常用命令

操作 命令 说明
创建轻量标签 git tag v1.0 简单标记某个版本
创建带注释标签 git tag -a v1.0 -m "Release 1.0" 推荐方式，含描述信息
查看标签 git tag 列出所有标签
查看标签详情 git show v1.0 查看该标签对应的提交信息
推送标签到远程 git push origin v1.0 推送单个标签
推送所有标签 git push origin --tags 一次推送所有标签
删除标签 git tag -d v1.0 删除本地标签

七、远程仓库（Remote）

远程仓库的作用

远程仓库是项目的 共享中心，团队成员可以推送（push）或拉取（pull）代码。
例如：GitHub、Gitee、GitLab。

常用命令

操作 命令 说明
关联远程仓库 git remote add origin <url> 添加远程地址
查看远程信息 git remote -v 查看绑定的远程仓库
推送到远程 git push origin main 推送当前分支
拉取更新 git pull origin main 拉取远程并合并
克隆仓库 git clone <url> 从远程复制项目到本地

八、忽略文件：.gitignore

.gitignore 文件定义哪些文件不应被 Git 跟踪。

常见内容示例：

# 忽略日志文件
*.log

# 忽略依赖目录

# 忽略系统文件

用途：

  • 避免提交编译文件、临时缓存等无关文件。
  • 保持仓库干净，减小体积。

九、配置与身份信息

操作 命令 说明
设置用户名 git config --global user.name "Your Name" 提交记录的作者名
设置邮箱 git config --global user.email "you@example.com" 提交记录的邮箱
查看配置 git config --list 查看全局配置项

⚠️ 一般首次安装 Git 时必须配置用户名与邮箱，否则无法提交。

十、查看差异与撤销

操作 命令 说明
查看工作区与暂存区的区别 git diff 查看未暂存的修改
查看暂存区与上次提交的区别 git diff --cached  
撤销最近提交（保留修改） git reset --soft HEAD~1  
丢弃所有未提交修改 git reset --hard HEAD 恢复到上次提交状态
